# ChainProof Mobile Application Guide

## Architecture Overview

The ChainProof Mobile Application is built with **React Native and Expo**, providing SecOps engineers and platform managers with an on-the-go security cockpit on **Android and iOS**.

```text
+-----------------------------------------------------------+
|              ChainProof Mobile Client (Expo)              |
|                                                           |
|   • Security Dashboard & Average Risk Posture             |
|   • Remote Container Scan Trigger                         |
|   • Real-Time Threat Alerts & Push Notifications          |
|   • SBOM Package & CVE Breakdown Inspection               |
|   • Machine Learning Risk & Anomaly Assessment            |
|   • Registry Watch Lists & Automation Management          |
+-----------------------------+-----------------------------+
                              |
                       Secure HTTPS
                              |
                              v
+-----------------------------------------------------------+
|           ChainProof Cloud Security API (FastAPI)         |
|                                                           |
|   • Host Docker Daemon Engine                             |
|   • Anchore Syft SBOM Generator                           |
|   • Docker Scout CVE & Remediation Scanner                |
|   • Sigstore Cosign Verification                          |
|   • Random Forest + Isolation Forest Inference            |
|   • AI Security Correlation Engine                        |
+-----------------------------------------------------------+
```

---

## Critical Mobile Architectural Constraints

> [!IMPORTANT]
> **Mobile clients DO NOT run Docker, Syft, Docker Scout, or Cosign locally.**
> Mobile operating systems (Android/iOS) cannot run the Docker daemon or privileged supply-chain container analysis CLI tools. Mobile acts exclusively as a secure remote control, monitoring, and alerting client. All container scans are executed by the Docker-capable Linux Cloud Scanner or Desktop Agent.

## Screen & Feature Breakdown

### 1. Security Dashboard (`src/screens/DashboardScreen.js`)
- Overall cluster metrics: total scanned images, critical risk count, total CVEs, and average supply-chain risk score.
- On-demand remote scan dispatch: triggers a full container scan on the Cloud backend.
- Feed of recent container audits with status badges.

### 2. Deep-Dive Scan Inspection (`src/screens/ScanDetailScreen.js`)
- **AI Correlation Engine**: Displays contextualized security assessments and actionable remediation recommendations.
- **Docker Metadata**: Reports image byte size and layer count.
- **Vulnerabilities**: Categorized count of Critical, High, Medium, and Low CVEs.
- **SBOM Inventory**: Package count and package details (name, version, type) generated by Syft.
- **Cryptographic Signature**: Cosign verification status (Verified vs Unverified).
- **Machine Learning Inference**: Random Forest prediction probabilities and Isolation Forest anomaly flags.
- **Findings**: Comprehensive list of security findings.

### 3. Automations & Schedulers (`src/screens/AutomationsScreen.js`)
- View active scheduled audits, registry listeners, and CI/CD policy gates.
- Trigger on-demand manual executions of any automation rule (`POST /api/v1/automations/{id}/run`).

### 4. Monitored Repositories (`src/screens/MonitoredImagesScreen.js`)
- Monitor critical production container images (e.g. `ghcr.io/org/repo:latest`).
- Add or remove images from the continuous watch list.

### 5. Alerts & Threat Feed (`src/screens/AlertsScreen.js`)
- Real-time notification ledger filtered by severity (`CRITICAL`, `HIGH`, `INFO`, `ALL`).
- Displays channel delivery status (Mobile Push, Webhook, Email, Desktop).

### 6. Settings & Diagnostics (`src/screens/SettingsScreen.js`)
- Custom Cloud API URL configuration (`https://api.yourdomain.com/api/v1`).
- Endpoint health probe displaying live status of Docker, Syft, Scout, and Cosign on the backend.
- One-click registration for Expo / FCM mobile push tokens.

## Running the Mobile Application

### Step 1: Install Dependencies
```bash
cd mobile
npm install
```

### Step 2: Start Expo Development Server
```bash
npm start
# Or using npx expo:
npx expo start
```

### Step 3: Launch on Devices
- **Physical Device**: Scan the QR code displayed in the terminal using the **Expo Go** app on Android or the Camera app on iOS.
- **Android Emulator**: Press `a` in the terminal (ensure Android Studio emulator is running).
- **iOS Simulator**: Press `i` in the terminal (requires macOS with Xcode).
- **Web Preview**: Press `w` to preview in a desktop browser.

## Building Standalone Mobile Binaries (EAS Build)

To generate production `.apk` / `.aab` for Android and `.ipa` for iOS:

```bash
# Install Expo Application Services CLI
npm install -g eas-cli

# Login to Expo
eas login

# Build Android APK
eas build --platform android --profile preview

# Build iOS Application
eas build --platform ios --profile preview
```
